# Phase 4 pattern map

The repository contains operational Markdown and no production application to copy. Use `docs/baseline-001.md` for the Verified / Method / Limit distinction, `docs/series-plan.md` for source-packet requirements and `docs/research/runtime-personality.md` for unrun comparison labeling.

New example files are self-contained standard-library modules with JSON fixtures and unittest tests; there is no pre-existing exported code interface. Plans explicitly define callable signatures and behaviors. No new UI, ORM, SDK, package install or live runtime import is part of this phase.
