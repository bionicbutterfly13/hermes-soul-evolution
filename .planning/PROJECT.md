## Constraints

- **Authorship:** Quill alone drafts and revises blogs. Its actual dispatch path is blocked by an exact-root access boundary in the current session; do not substitute another writer.
- **Execution:** Plan now; no automatic advance into implementation. Future live interventions require a separate scoped task after evidence and source inspection.
- **Git:** Each issue gets a separate codex/ branch and sibling linked worktree from verified main. Open feature lanes remain available while work is pending.
- **Evidence:** Every improvement claim requires an observed result, dated provenance and stated limits. Existing operator observations are not independently reproduced.
- **Examples:** Prefer Python standard library and synthetic fixtures; no dependency installation is required by these plans. Public examples must be runnable and tested.
- **Colab:** Optional execution environment. Add a notebook/run claim/link only after an actual Colab run and retained execution evidence.
